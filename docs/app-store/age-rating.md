# Age rating questionnaire

App Store Connect → App Information → Age Rating. Answer exactly this; the result is **18+**.

| Question | Answer | Why |
|---|---|---|
| Parental controls / age assurance | No | The app has an in-app age confirmation, not an age-verification system |
| Unrestricted web access | No | No web views or browser |
| User-generated content | No | Nothing is published or shared with strangers; content only goes to phones the host admits, or files the user sends themselves |
| Messaging and chat | No | Tasting notes are not a chat feature |
| Advertising | No | |
| Alcohol, tobacco, or drug use or references | **Frequent / Intense** | The whole app is about alcohol tastings |
| All violence, sexual, profanity, horror, gambling, contests, medical questions | None / No | |
| Loot boxes | No | |
| Health or wellness topics | No | |

The app also asks every user on first launch to confirm they're of legal drinking age and refuses
to continue if they say no, and keeps a responsible-drinking note and the SAMHSA helpline in
Settings. App Review guideline 1.4.3 rejects apps that *encourage* excessive drinking; Drunkin's
copy is about scoring and comparing, never about drinking more. Keep it that way in future
features (no drinking games, no "take a shot" mechanics, no counters that reward volume).
